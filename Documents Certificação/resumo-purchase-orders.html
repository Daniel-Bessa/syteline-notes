Receiving Purchase Orders
Resumo de estudo — Workbook de certificação
Resumo
🎯 Visão geral do curso e do processo Procure To Pay ▶
•Curso SyteLine: Receiving Purchase Orders (código 01_0012209_IEN3777_SYT) — cobre os conceitos fundamentais de receção dentro do Procure To Pay, no papel de receiving clerk. Duração total: 1,25 horas.
•Estrutura: Course overview (0,25h) → Lição 1 Using Procure To Pay (0,25h) → Lição 2 Receiving purchase orders (0,25h) → Lição 3 Returning purchase orders (0,50h) → Course summary.
•Pré-requisitos: SyteLine: Navigating the User Interface e SyteLine: Foundation.
•Público-alvo: Customer User, Pre-Sales Consultant, Business Consultant, Technical Consultant, Support e System Administrator.
•Purchasing permite entrar, gerar, monitorizar e receber purchase orders (PO), melhorando a gestão de stock e dos movimentos de material.
•O Infor Industry Process Catalog (IPC) para o CloudSuite Industrial (SyteLine) fornece conteúdo pré-configurado (configurações, processos, casos de teste) alinhado com a indústria do cliente — no curso é referido como "business process".
•Procure To Pay = comprar itens a fornecedores, recebê-los, pagar fornecedores e devolver itens para crédito. Tem 4 componentes principais; este curso foca-se apenas em Purchase Order To Receipt e Return To Debit.
•Purchase Order To Receipt process: gere os requisitos de compra com fornecedores, terminando com a receção das linhas do PO em stock — assegura que os itens corretos são recebidos e autoriza os pagamentos ao fornecedor.
•Return To Debit process: usado para devolver um item a um fornecedor (ligado ao processo de devoluções da Lição 3).
💡 Capacidades-chave do curso: definir parâmetros/tolerâncias para receção de PO; receber encomenda ou linha/release completa ou parcial; devolver mercadoria ao fornecedor.
⚙️ Purchasing Parameters — tolerâncias de PO ▶
•O form Purchasing Parameters define valores por defeito usados em toda a área de compras (separador General). Normalmente é configurado por um Administrator.
•PO Tolerance Over (%) — determina quanto se pode receber ACIMA da quantidade encomendada. Pode ficar em branco, 0 ou um número positivo:
–Em branco → pode receber qualquer quantidade acima do encomendado.
–0 → só pode receber exatamente o que foi encomendado, nada mais.
–Número positivo → pode receber até ao limite de tolerância (mostra aviso); acima desse limite o sistema mostra erro.
•PO Tolerance Under (%) — determina quanto se pode receber ABAIXO da quantidade encomendada, e quando o status da linha do PO passa a Filled:
–Em branco → qualquer quantidade abaixo é aceite; status só fica Filled quando recebido ≥ encomendado.
–0 → tem de receber exatamente o encomendado para ficar Filled.
–Número positivo → pode receber abaixo até ao limite inferior; status fica Filled quando recebido ≥ limite de tolerância.
💡 Quando o campo Source de um item é definido como Purchased, os valores de PO Tolerance Over/Under do Purchasing Parameters servem apenas como valor inicial por defeito no form Items/Multi-Site Items — depois disso, é o valor gravado no próprio item que é usado durante a receção real do PO (o Purchasing Parameters não é reconsultado). Se o Source deixar de ser Purchased, o campo fica a null e é desativado.
•Use PO Tolerance % for Non-Inventory Items: checkbox para aplicar as tolerâncias também a itens não inventariados. Se não estiver marcada, continua a aparecer um aviso ao sobre-receber uma linha de PO não inventariada.
📥 Purchase Order Receiving form — receção de linhas ▶
•O Purchase Order Receiving form é usado para receber linhas de um PO. Ao receber, é criada uma material transaction.
•Pode-se selecionar um PO específico ou um vendor (mostra todos os POs desse fornecedor).
•Ao selecionar um PO, todas as linhas ainda por receber carregam para um batch file — dá para adicionar, atualizar ou apagar linhas específicas, ou receber tudo de uma vez.
•Change Warehouse (menu Actions): só se recebem linhas de um warehouse de cada vez — usar esta opção para mudar de warehouse.
•Botões principais: Add Line (abre Add Receiving Line form), Add Purchase Order (abre Add PO form), Select All / Deselect All, Clear All, e Receive (recebe as linhas selecionadas).
•No separador Detail, o campo Destination determina como a linha é recebida (ex.: se Destination = Inventory, o item entra em Inventory). Se o item for lot-tracked, abre o modal Add Lots.
•O separador Supplementary mostra Ordered quantity, Received quantity, Rejected quantity, Order Date e Last Rcvd.
💡 PO Receiving List form: gera/imprime uma lista tipo "pick list" dos itens de um PO para ir marcando à medida que se recebe (inclui lote, localização e nº de item do fornecedor). O checkbox Post Material Receipts — se marcado, o sistema recebe automaticamente as transações de todos os itens do PO; se desmarcado, as transações têm de ser concluídas manualmente. Em ambos os casos imprime-se sempre uma cópia da lista.
💡 Se um item recebido for reservado e estiver cross-referenced a uma ordem, o sistema cria automaticamente uma reserva igual a (qtd encomendada − qtd expedida + qtd devolvida − qtd reservada), até ao valor recebido; o que sobrar vai para inventário.
🛠️ Troubleshooting e impactos no sistema ▶
•Se não conseguir receber um PO, o primeiro passo é verificar o status. Se estiver Planned, há duas formas de corrigir:
–Purchase Order Report — marcar o checkbox Post Status Changes antes de imprimir.
–Purchase Order Lines — mudar manualmente o status para Ordered.
•Forms/campos para confirmar que um PO foi recebido com sucesso:
–Purchase Order Lines - Costs: campo Received = total recebido; Last Rcvd = data atual.
–Purchase Order Listing: Status = Filled; campo Received atualizado.
–Items - Detail / Item Stockroom Locations: verificar Quantity on Hand, Location e Location on Hand.
–Journal Entries - PO Dist: na coluna de referência aparece INV PRCV (Inventory Purchase Receiving) para o PO/linha — débito a Inventory Material e crédito a Vouchers Payable.
–Vouchers Payable Report e Material Transactions — para revisão adicional das transações geradas.
↩️ Devoluções ANTES de vouchering ▶
•As devoluções de PO fazem-se sempre no Purchase Order Receiving form. Podem ser geradas antes de vouchering ou depois de vouchering (chamada de Debit return).
•Quando a linha ainda não foi vouchered (não faturada):
–O checkbox DR Return não fica disponível — se tentar marcar e o sistema não deixar, é sinal de que a linha ainda não foi vouchered e por isso tem de fazer uma devolução negativa.
–Introduzir uma quantidade negativa no campo Receive Qty.
–Selecionar a localização de stock de onde a devolução é feita.
–Indicar um reason code que identifique o motivo da devolução.
💡 Exemplo do exercício (2.1 / 3.1): PO dp189, filtrar PO Line/Release Status = Filled, selecionar a linha, Receive Qty = -3, reason code = WIS (recebido verniz em vez de tinta por engano).
💳 Devoluções APÓS vouchering (Debit Return) ▶
•Quando a linha já foi vouchered (faturada / associada a uma invoice):
–O checkbox DR Return TEM de ser selecionado.
–Introduzir uma quantidade positiva no Receive Qty.
–Selecionar a localização de stock de onde a devolução é feita.
–Indicar um reason code.
⚠️ Para conseguir usar o checkbox DR Return: o valor do voucher tem de ser maior que zero e o checkbox To Container tem de estar desmarcado.
•Se os itens forem recebidos numa localização non-nettable e, após inspeção, houver rejeições, pode-se indicar uma quantidade positiva no campo Reject Qty para atualizar o histórico YTD de rejeições do fornecedor.
•Itens serializados: usar o separador Serial Numbers para escolher o(s) número(s) de série a devolver (comparar Target Qty com Selected Qty).
💡 Exemplo do exercício (3.2): devolução de 1 Tablet Computer (TC-11000, serializado, já matched a uma invoice) — reason code = PVQ, DR Return marcado, Receive Qty = 1.00, seleção do número de série no separador Serial Numbers.
📝 Fluxos práticos — passo a passo resumido ▶
•Gerar lista de receção (PO Receiving List):
  1. 1Open (toolbar) → filtrar "PO receiving" → abrir PO Receiving List form.
  2. 2Introduzir o nº do PO → Tab.
  3. 3Clicar em Print — a lista abre num novo separador (Item, Location, Qty Ordered, To Receive).
•Receber linhas de um PO:
  1. 1Open → filtrar "purchase order receiving" → abrir Purchase Order Receiving form.
  2. 2Introduzir o nº do PO → Tab.
  3. 3Selecionar (Select checkbox) a(s) linha(s) a receber; confirmar Receive Qty e Location.
  4. 4Clicar em Receive → confirmar a mensagem de "Pending PO Receiving Transaction(s) were posted".
•Fazer uma devolução: abrir o mesmo form → filtrar PO Line/Release Status = Filled → selecionar a linha → tentar DR Return (indica se já foi vouchered ou não) → Receive Qty negativa (antes) ou positiva (depois) → reason code → (se serializado, escolher no separador Serial Numbers) → Receive.
💡 Estes passos correspondem aos Exercícios 2.1 (receção de uma blanket PO), 3.1 (devolução antes de vouchering) e 3.2 (devolução após vouchering, item serializado) do workbook.
